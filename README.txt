Guessing Game Project

Files included:
- Main.java
- GUI.java
- Level.java
- Difficulty.java
- User.java
- PlayerUser.java
- AdminUser.java
- Leaderboard.java
- LeaderboardEntry.java

Features:
- Swing GUI
- Inheritance (User -> PlayerUser/AdminUser)
- Difficulty selection
- Leaderboard saved to leaderboard.txt
- Admin can clear leaderboard
- NetBeans project structure included

Open in NetBeans:
1. Extract the ZIP file.
2. Open NetBeans.
3. Choose File -> Open Project.
4. Select GuessingGameProject.
5. Run the project.
